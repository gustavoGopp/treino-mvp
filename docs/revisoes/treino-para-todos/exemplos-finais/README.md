# As doze pessoas: a semana de antes da etapa 2 ao lado da semana de agora

> Sessão "treino para todos", fechamento da etapa 2 (17/11/2026). Todas as pessoas são fictícias. "Antes" é a semana que a `main` dava quando a etapa 2 começou; "Depois" é a semana do app neste ramo, com os pacotes 0 a 5 e a marca do ombro. As notas são de três revisores no papel de treinadores, que não sabiam qual semana era qual (`../revisao-cega/final/`). É opinião de treinador simulado, não evidência. Cinco das doze semanas não mudam: são as pessoas que treinam em casa com pouco ou nenhum equipamento, onde quase não há escolha a fazer.
